CosmosAPI - Caracteristicas actuales

Autor: devpapo
Plataforma: Spigot 1.21.x
Build: Maven (pom.xml)
Paquete base: com.devpapo.cosmosapi

COSMOS (MONEDAS VIRTUALES)
- Soporta multiples monedas virtuales llamadas "cosmos".
- Los datos de cosmos y balances se guardan en archivos YAML.
- Cada cosmo tiene nombre interno y nombre visible con colores.
- Se pueden usar colores legacy (&a, &c, etc.) y colores RGB/hexadecimales.

TIPOS DE RECOMPENSA
- Tiempo conectado.
- Matar jugadores.
- Matar mobs.
- Romper bloques.
- Colocar bloques.

COMANDOS
- /cosmo create <nombre> <tipo> <cantidad>
- /cosmo displayname <cosmo> <nombre_visible>
- /cosmo delete <nombre>
- /cosmo give <cosmo> <jugador> <cantidad>
- /cosmo set <cosmo> <jugador> <cantidad>
- /cosmo send <cosmo> <jugador> <cantidad>
- /cosmo menu create <nombre> <tipo> <tamano>
- /cosmo menu open <nombre>
- /cosmo menu delete <nombre>
- /cosmo view
- /cosmo tops
- /cosmo reload
- /cosmo help

ALIAS
- /cosmos funciona como alias de /cosmo.

MENUS Y TIENDAS
- Menus configurables desde menus.yml.
- Soporta inventarios de cofre, dispensador y horno.
- Los items de las tiendas se pueden comprar usando un cosmo elegido.
- /cosmo view abre un menu paginado con los menus creados y los saldos del jugador.
- /cosmo tops muestra el top 15 de jugadores para cada cosmo.
- /cosmo reload aplica los cambios realizados en configuracion sin reiniciar el servidor.

AUTOCOMPLETADO
- Tab completion para subcomandos, nombres de cosmos, jugadores, tipos de recompensa y tamanos de menu.

PERMISOS
- cosmos.admin
- cosmos.send
- cosmos.view

PLACEHOLDERS (PLACEHOLDERAPI / TAB)
- Requisito: instala PlaceholderAPI en el servidor. CosmosAPI detecta PlaceholderAPI al iniciar y registra sus placeholders automáticamente.
- Tras instalar PlaceholderAPI o CosmosAPI, reinicia el servidor. No se necesita descargar una expansión con /papi ecloud.
- TAB puede usar los placeholders directamente en su scoreboard, tablist, nametag o cualquier sección compatible con PlaceholderAPI.
- %cosmosapi_<cosmo>% : saldo del jugador en ese cosmo. Ejemplo: %cosmosapi_gemas%.
- %cosmosapi_<cosmo>_displayname% : nombre visible y coloreado del cosmo. Ejemplo: %cosmosapi_gemas_displayname%.
- %cosmosapi_cosmos% : lista de IDs de los cosmos disponibles, separados por comas.

EJEMPLO PARA TAB (config.yml DE TAB)
scoreboards:
  default:
    title: '&d&lCOSMOS'
    lines:
      - '&fGemas: &d%cosmosapi_gemas%'
      - '&fMonedas: &6%cosmosapi_monedas%'

El ID usado en el placeholder es el nombre interno creado con /cosmo create, no el displayname.
Por ejemplo, si ejecutas /cosmo create gemas mob_kill 2, el placeholder de saldo será %cosmosapi_gemas%.
Usa /papi parse me %cosmosapi_gemas% para comprobar el resultado dentro del servidor.

ARCHIVOS
- config.yml: configuracion y mensajes.
- cosmos.yml: definiciones de las monedas virtuales.
- menus.yml: menus y productos de tienda.
- players.yml: balances de jugadores.

PENDIENTE DE REVISION
- plugin.yml debe tener como clase principal:
  main: com.devpapo.cosmosapi.CosmosAPI
- El groupId de pom.xml debe coincidir con com.devpapo para mantener el proyecto consistente.
